⚠️ 蓝牙受限提示：当前以 file:// 打开。现代浏览器因安全策略限制本地文件使用蓝牙，请在 http://localhost 打开。

🛡️ 蓝牙连接权限解决指南

报错 Access to the feature "bluetooth" is disallowed by permissions policy 是现代 Chrome / Edge 浏览器的核心安全限制（Permissions Policy），严禁在本地静态文件（file:// 协议）或未授权 iframe 中直接调用 Web Bluetooth API。

🚀 推荐方法 1：Mac 双击一键启动（最快捷）

已在当前下载目录生成了一键启动脚本，无需输入命令：

👉 打开 访达 (Finder) ➔ 下载 (Downloads) ➔ 双击 双击启动3D魔方.command

系统将自动启动轻量本地服务器，并在 Chrome 中以 http://localhost 形式打开，蓝牙权限自动完全开放！

💻 方法 2：终端一行命令启动

打开 Mac 终端 (Terminal)，粘贴并运行以下命令：

cd "/Users/shenruqi/Downloads" && python3 -m http.server 8080

启动后在 Chrome 访问：http://localhost:8080/3d%20(2).html 即可畅享蓝牙连接！

🧩 方法 3：若在 iframe / 预览器中嵌入

若在 IDE 内置预览器或第三方网页的 <iframe> 中嵌入该页面，需为 iframe 补充蓝牙授权属性：

<iframe src="..." allow="bluetooth; bluetooth-fallback"></iframe>
